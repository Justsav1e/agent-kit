# Complex work

Create a durable artifact only when the task spans sessions, needs review,
or has decisions another agent must preserve. Reuse project documentation.

Keep the task contract short: goal and user outcome; observable acceptance;
constraints and non-goals; current behavior; affected areas; risks; verification.
Distinguish known facts from assumptions. Clarify material unknowns while
continuing independent work.

For a new product establish the primary user and complete journey before
choosing abstractions. For a refactor identify exactly what behavior must remain
unchanged. For a bug prove the failure path before changing it. Performance
work needs a before/after measurement of equivalent behavior.

A plan step states an outcome, area, invariant and check. Implement one coherent
behavior at a time; avoid batches of empty abstractions. Do not reopen accepted
design without new evidence. Shared CSS, APIs and storage need impact inspection.

At a clean boundary record objective, decisions, constraints, state, files,
checks, unresolved items and next step. Include the branch/worktree and evidence
locations where relevant. No transcript or full repository summary is needed.

Heavy reasoning is optional: pass a focused problem and evidence to a consultant
only if justified and available. Validate its memo against source. The main
agent must remain able to continue without the consultant.
